# Módulo 01 – Lógica Proposicional

Estudo dos conceitos básicos de lógica proposicional aplicados à programação.

## Conteúdos

• O que é proposição
• Operador E (conjunção)
• Operador OU (disjunção)
• Operador NÃO (negação)
• Operador OU Exclusivo (XOR)
• Operador SE ENTÃO
• Operador SE E SOMENTE SE

Aprendizados:

Negação:
- Inverte o valor lógico de uma proposição.

OU Exclusivo:
- É verdadeiro quando apenas uma condição é verdadeira.

SE ENTÃO:
- Representa uma relação de condição e consequência.

SE E SOMENTE SE
- Ele é verdadeiro apenas quando ambas as sentenças são verdadeiras ou ambas são falsas.

Exemplos:

1) NÃO (Hoje está chovendo)
2) Vou ao cinema OU EXCLUSIVO vou ao teatro
3) Se eu estudar programação, então aprenderei lógica.
4) Se sou brasileiro e nasci no Brasil
