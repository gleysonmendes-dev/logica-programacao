# Módulo 03 – Lógica de Programação na Prática

Aplicação prática dos conceitos fundamentais de programação utilizando o VisuAlg.

## Conteúdos

### Tipos de dados
- Inteiros
- Decimais
- Cadeia de caracteres
- Caracteres
- Vetores e matrizes
- Booleano

### Estruturas básicas
- Variáveis
- Constantes
- Concatenação

### Operadores
- Aritméticos
- Relacionais
- Lógicos

### Outros conceitos
- Agrupamento com parênteses

## Objetivo

Praticar os conceitos básicos de programação antes de avançar para estruturas condicionais e de repetição.
