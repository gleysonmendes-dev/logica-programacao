# Lógica de Programação

Repositório dedicado ao estudo de lógica de programação, algoritmos e fundamentos,
baseado no curso LogicamentePro.

## Conteúdos estudados
- Lógica proposicional
- Algoritmos e pseudocódigo
- Operadores e tipos de dados
- Estruturas condicionais e de repetição
- Vetores, matrizes e funções

## Objetivo
Construir uma base sólida em lógica de programação para aprender linguagens
como JavaScript, Python ou Java no futuro.

Conteúdos concluídos:

- Operador de Negação (NÃO)
- Operador OU Exclusivo (XOR)
- Operador SE ENTÃO
- SE E SOMENTE SE

Aprendizados:

Negação:
- Inverte o valor lógico de uma proposição.

OU Exclusivo:
- É verdadeiro quando apenas uma condição é verdadeira.

SE ENTÃO:
- Representa uma relação de condição e consequência.

SE E SOMENTE SE
- Ele é verdadeiro apenas quando ambas as sentenças são verdadeiras ou ambas são falsas.

Exemplos:

1) NÃO (Hoje está chovendo)
2) Vou ao cinema OU EXCLUSIVO vou ao teatro
3) Se eu estudar programação, então aprenderei lógica.
